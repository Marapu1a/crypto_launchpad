# Хаб

Публичные исходники: `site/`. Каталог `site/projects.json` используется также ботом
и сборкой сайтов. Из корня: `npm run catalog:check`, `npm run hub:preview` (:4212).
Общий preview: `npm run sites:build` и `npm run sites:preview` (:4202).
Изменение исходников само по себе не публикует сайт.
