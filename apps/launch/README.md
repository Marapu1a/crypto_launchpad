# Интерфейс запуска

Здесь HTML-страницы и клиентские entrypoints. Общие модели остаются в `src/` корня,
API — в `server/`. Из корня: `npm run dev` и `npm run build`.
Vite-конфигурация в корне; output остаётся `dist/` для совместимости серверов
и release-команд. URL страниц не изменены.

Перенос интерфейса не меняет разрешения на подписи и не запускает обслуживание.
