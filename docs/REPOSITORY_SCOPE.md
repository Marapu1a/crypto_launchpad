# Что сохраняем в репозитории

21.10.2026, согласовано задачей владельца разобрать, закоммитить и отправить
текущий пакет перед проверкой PW.

## Публикуем

- Исходники работающего бесплатного монитора, уведомлений и общего бота.
- Исправления RPC/ожидания receipts, общие политики обслуживания токенов,
  тесты и результаты в текстовых отчётах с пределами проверки.
- Согласованные продуктовые решения, схемы БД, безопасные примеры конфигураций,
  systemd/nginx templates, scripts, package.json и lockfile зависимостей.
- Ответы независимого GPT и историю решений.

## Сохраняем как отключённые наработки

`server/monitor-billing`, старые access/alerts UI и billing runner/test — прежний
прототип подписки; не включать в production. Общий код уведомлений пока использует
из billing core только вспомогательные функции, это не включает оплату.
`market_signals.py`, `/signals` и replay — исследовательский подробный журнал,
не основной пользовательский сценарий и не действующий detector коллектора.
Наличие этих файлов не отменяет [бесплатную модель](MONITOR_SCOPE_20261021.md).
Сохраняем код и тесты, а не незадокументированную копию в ignored-папке.

## Не публикуем

`.local/`, настоящие bot/VAPID/ingress-секреты, RPC URL с ключами, keystore и
пароли кошельков, production-конфиги, SQLite/PostgreSQL данные и дампы,
состояние бота/offset/чаты/подписки, журналы, backup, скриншоты прогонов,
архивы развёртывания и manifests конкретной установки, node_modules/build artifacts.
`.gitignore` закрывает обычные пути и форматы; перед push дополнительно проверять
состав staged-файлов и известные секреты. Ignore не очищает уже tracked-файлы.

## Граница текущего push

Два отдельных пакета: исправления RPC, затем бесплатный сайт/бот и документация.
Отчёт проверки токена — последующий отдельный коммит. Git commit не является
разрешением на выпуск токена или транзакции. Подготовленный токен остаётся выключенным.
Серверные releases собраны из зафиксированных в их отчётах файлов; весь HEAD
автоматически на сервер не устанавливается.
