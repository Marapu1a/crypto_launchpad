# Локальный монитор активности Pons

Обновление 13.10.2026: [метрики первого часа и проверки](archive/reports/MONITOR_METRICS_20261013.md).
Таблица теперь показывает кошельки, покупки, объём, максимум, медиану, топ-3 и X;
доступны окна последних пяти минут и времени с запуска. Описание ниже фиксирует
исходный пакет от 11.10.2026.

11.10.2026. Дополнительная гипотеза перед IGW, не автоматический трейдер.

Адрес: http://127.0.0.1:4196/ . Запуск: `python apps/monitor/monitor.py`.
Локальный процесс работает отдельно от студии, QIANQI и production.
Ключи, RPC, кошельки и отправка транзакций не используются.

## Что измеряется

Публичные GET endpoints Pons `/api/launches?sort=newest` и
`/api/launches/{address}?view=trades`. Опрос примерно раз в минуту,
не WebSocket и не мгновенный on-chain feed. При медленном API цикл удлиняется.
При старте загружается история; фон — шесть предыдущих пятиминуток,
текущее окно — последние пять минут, с отступом 60 секунд для индексации.

Учитываются curve BUY событий токенов V2 в первый час их жизни.
Адрес создателя исключён, связанные кошельки не определяются.
Повторы страниц удаляются по паре token/address + event/id.
Покупатели — уникальные адреса за интервал, не доказанные люди.
ETH и другие валюты не складываются; отдельно показана сумма покупок USDG.

Экспериментальный сигнал: число покупок и покупателей ≥1,8 от среднего
предыдущих шести пятиминуток, минимум10 покупок,8 кошельков,3 токена.
Нулевой фон не даёт сигнал. Число запусков показано отдельно как конкуренция;
это не автоматический критерий отправки или доказательство хорошего момента.

Лимиты сбора:15 страниц запусков,20 страниц сделок на токен,4 параллельных
запроса, timeout15с. Если истории недостаточно, API недоступен или конец окна
отстаёт больше240с, сигнал отключён. Полнота означает полноту в рамках API,
не независимую проверку всех торговых маршрутов или finalized chain state.

## Эксплуатация

Нажать «Включить звук»: браузер требует действие пользователя для аудио.
Проверочный звук прозвучит сразу; при сигнале повторяется не чаще раза в5 минут.
Вкладка должна оставаться открытой, компьютер включённым; фоновые вкладки
могут замедляться браузером. Локальный сборщик работает независимо от вкладки.

Сводки циклов: `.local/pons-monitor/observations.jsonl` (append-only).
PID текущего скрытого процесса: `.local/pons-monitor/pid.txt`;
stdout/stderr и снимки экрана находятся рядом. Перезапуск заново читает фон из API.
Остановка: проверить командную строку PID и остановить только этот Python-процесс.

Проверки: `python apps/monitor/test_monitor.py` — исключение создателя,
дедупликация, границы возраста/времени, широкий всплеск и нулевой фон.
Браузер: desktop/mobile, отсутствие JS ошибок и горизонтального переполнения,
кнопка включения звука. Результаты live-проверки сохраняются локально.
