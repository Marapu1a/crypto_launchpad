# Рыночные сигналы: наблюдение без отправки

20.10.2026. Основание: согласованный пакет после
[независимого ревью](GPT_MONITOR_SIGNALS_REVIEW_20261020.md), HEAD `31f9e7a`.
Реализация проверена локально, на сервер не опубликована.

## Границы

Два сигнала по наблюдаемым покупкам Pons V2 на кривой в первый час,
без покупок создателей. Это не весь рынок Pons и не торговая рекомендация.
Используются уже сохранённые пятиминутные агрегаты: новых RPC/API-запросов нет.
Результаты записываются в отдельный `market-signals.sqlite3` рядом с базой монитора.
Отправки и постановки сообщений в очередь нет. Telegram/Web Push остаются
отдельным последующим этапом; сигналы кошельков выключены по умолчанию.

## Экспериментальные правила

- Устойчивое оживление: два последовательных полных окна одновременно превышают
  пороги покупателей и покупок. База — медианы 12 окон перед обоими окнами события.
  Начальные пороги: max(12 покупателей, 1.8 × медиана) и
  max(20 покупок, 1.5 × медиана).
- Всплеск объёма: объём одного полного окна >= max(нижняя граница, 3 × медиана
  12 предыдущих окон). ETH и USDG считаются отдельно, без пересчёта по курсу USD.
  Начальные границы: 0.05 ETH и 100 USDG.
- Одна крупная покупка не исключается: событие сохраняется с отметкой концентрации.
  Изменение цены валюты пары само по себе не создаёт сигнал.

Эти числа — стартовые настройки shadow-прогона из ревью, не согласованные пороги
боевых уведомлений. Лимита «три уведомления в день» нет: доставки пока нет вообще.
Конфигурация и её отпечаток сохраняются с решением.

Пропущенное/неполное окно, ошибка или неизвестная сумма не заменяются нулём.
Для новой оценки допускается возраст окна не более 15 минут.
Продолжающиеся причины объединяются в одно событие. Для завершения причины нужны
три последовательных полных окна ниже порога выхода, рассчитанного от исходной
базы: 1.2 для покупателей / 1.1 для покупок, 1.5 для объёма, с теми же нижними
границами. Для активности достаточно снижения одного из двух показателей.
Пропуск сбрасывает счётчик спокойных окон, но не закрывает событие.

Первое решение для окна неизменно: поздние исправления сохраняются отдельно,
повторных событий не создают. Более старое окно не изменяет текущее состояние.
Решения и исправления хранятся 28 дней; события и их исходные снимки пока не удаляются.

## Просмотр и проверка истории

`/signals` — список событий; `/signals?id=...` — сохранённые причины, пороги,
исходные окна и база сравнения. Отсутствующий ID не подменяется последним событием.
API публикует только агрегаты, без списков кошельков и сырых операций.

Локальный просмотр: http://127.0.0.1:4221/signals . Здесь реальные сохранённые
агрегаты, помеченные как исторический прогон; соседний preview кошельков демонстрационный.

Прогон `scripts/replay-market-signals.py` читает исходную SQLite только для чтения
и требует отдельный выходной файл. `--resume` допустим для той же неизменной базы
и конфигурации после прерванного запуска.

Локальный результат 20.10.2026: 1405 окон за 13–19 октября, 19 событий;
69 решений candidate, 100 clear, 1046 continuing, 190 insufficient.
Число candidate не равно числу отдельных событий. Долгие эпизоды требуют просмотра
и настройки условий завершения до включения доставки.
Это реконструкция сохранённой истории: первоначальные версии данных на момент
каждого сбора недоступны. Прогон не доказывает качество сигналов в реальном времени.
Выходной файл: `.local/market-signals-review-20261020.sqlite3`.

Проверены 10 тестов правил/журнала, 10 тестов надёжности коллектора,
7 тестов монитора; браузерные проверки токенов и кошельков.
Страница сигналов проверена на реальном локальном прогоне: список, исходный ID,
отсутствующий ID, три языка, ширины 1440/390/320, отсутствие JS-ошибок.

Следующий шаг: просмотреть события и долгие эпизоды, уточнить пороги/выход,
