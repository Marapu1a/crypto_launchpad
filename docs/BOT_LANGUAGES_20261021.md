## Поведение

`/start`, `/projects`, `/help` сразу показывают кнопки QIANQI, IGW и Pattern
Watcher. Карточка содержит описание, сайт, автора, X, контракт, Pons и обозреватель
там, где токен выпущен. Для PW показан работающий сайт и статус подготовки
токена; адреса контракта и ссылки на покупку нет. Поиск текстом остаётся
дополнительным способом, вводить тикер для навигации больше не требуется.
Каталог общий: `apps/hub/site/projects.json`. PW помечен `botOnly`, чтобы
существующий генератор старых карточек хаба с USDG-draw iframe не создавал
неверную карточку монитора. Публичный хаб этим пакетом не переоформляется.

Русский, английский и китайский доступны в меню, карточках, ответах подключения,
тестовых и рыночных уведомлениях. При первом прямом входе используется язык
Telegram; неподдерживаемые языки получают английский. `/language` или кнопка
Language открывает выбор. Язык Telegram сохраняется отдельно от языка сайта.

Подключение через сайт переносит его язык в одноразовую ссылку; этот выбор
действует и на ответ подключения, и на дальнейшие Telegram-уведомления.
Повторное осознанное подключение с сайта может изменить язык Telegram.
Смена языка сайта меняет Push для браузерной учётной записи; Telegram не
переключается автоматически. Несколько устройств одной browser-owner используют
один язык Push. Прежние подписки без языковой настройки сохраняют русский
до следующего подключения/выбора языка. Уже поставленные в очередь сообщения
не переводятся задним числом и не переотправляются.

## Хранение и установка

`server/monitor-alerts/schema.sql` дополнен таблицами `languages`,
`chat_languages` и полем языка в `links`. Изменения идемпотентны; выполнить
с резервной копией в БД уведомлений до переключения gateway и бота. Это
не миграция финансовой схемы launchpad. Существующие subscriptions, chats,
offset, dedup и секреты сохраняются. Второй getUpdates poller не запускать.

Bridge использует прежний защищённый endpoint для получения/сохранения языка.
Он проверяет private chat и совпадение from.id/chat.id, включая callback.
Недоступность gateway не мешает обычной навигации по каталогу; подключение,
отключение и смена языка показывают ошибку вместо ложного успеха. Локальное
состояние единственного poller хранит последний известный язык для навигации
при недоступном bridge. Смена языка не включает подписку.
