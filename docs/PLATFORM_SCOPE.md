# Границы платформы

Текущие правила — [PRODUCT_SPEC](PRODUCT_SPEC.md); состояние —
[CURRENT_CONTEXT](CURRENT_CONTEXT.md). Обновлено 13.10.2026.

| Область | Граница |
|---|---|
| Pons | Личный конструктор и проверенные версии интеграции; полное покрытие не заявлено |
| Новый draw v2 | Short/Monthly/оба реализованы и проверены на изолированных стендах; реальный IGW — Short |
| QIANQI | Отдельный существующий адаптер; не создаётся заново и не мигрируется автоматически |
| Сайты | Общий каталог и частично общие компоненты, собственное оформление токенов |
| Монитор | Сейчас локальный эксперимент первого часа; развитие и оплата пока в плане |
| Финансы | Отдельные кошельки/журналы/фонды; нет общего пользовательского кошелька |

Конструктор не даёт прав менять неизменяемые параметры Pons или уже frozen-циклы.
Сигнал монитора не разрешает запускать токен либо торговать автоматически.
Веб-публикация, новый deployment и запуск платной услуги — отдельные действия.
