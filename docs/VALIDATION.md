# Валидация базового запуска

Пакет 08.10.2026. Общие правила — `src/pons/validation.mjs`, серверная граница —
`server/api.mjs`. Форма подсвечивает поля, сохраняет ошибочный ввод для исправления,
блокирует переход вперёд и подготовку. Сервер повторяет проверку независимо от UI.

| Данные | Правило |
| --- | --- |
| Имя / тикер | 1–32 / 1–10, латиница и цифры; одиночные пробелы только в имени |
| Описание | До 256 Unicode code points, без скрытых управляющих символов |
| Логотип | `ipfs://`, CID разбирается multiformats, URI до 512 байт, безопасный путь |
| Локальный файл | PNG/JPEG/WebP, непустой, до 5 МиБ, квадрат до 4096 px; сервер проверяет реальный формат и декодирует пиксели |
| Соцсети | X/Telegram нормализуются; остальные ссылки HTTPS без credentials, до 256 байт после нормализации |
| Адреса | Полные адреса с проверкой checksum; нулевой только как обозначение ETH-пары |
| Creator fee | 0–10%, дополнительно актуальный cap и предел общей комиссии из условий Pons |
| Стартовая покупка | Неотрицательная, точность выбранного актива, предел uint256; пустое поле означает 0 |
| Проценты | До двух дробных знаков; проскальзывание меньше 100% |
| Числовой ввод | Точка или запятая; знаки, экспонента, NaN, объекты и числа вместо строк отклоняются |
| Исключения | До 32 адресов, до 31 при покупке; без дубликатов и нулевого адреса |
| Конфигурация | Существует и включена; пара одобрена; salt — bytes32 |

Снимок условий должен соответствовать паре и конфигурации и быть не старше
60 секунд. Перед подготовкой сервер перечитывает сеть: cap, decimals, разрешения,
балансы, allowance и economics hash. Симуляция проверяет защищённый calldata,
минимальный результат покупки и бюджет с оценкой gas. Реальная доступность средств
может измениться после проверки; это не резервирование баланса.

`POST /api/pons/prepare` принимает только draft/account/mode. Клиент не задаёт
RPC, лимиты, decimals или calldata. JSON до 32 КиБ; ошибки полей — 422, неверный
JSON — 400, превышение размера — 413. Ошибки RPC не раскрывают endpoint.
`POST /api/pons/image-check` принимает бинарное изображение, не публикует его.
Оба маршрута доступны в dev/preview и `npm start` после сборки. Сервер слушает
localhost; подпись и отправка основной сети в этот пакет не входят.

Пределы проверки: файл предпросмотра пока не связан с введённым CID; доступность
и содержимое уже опубликованного IPFS-объекта не проверяются. Эти проверки входят
в будущий пакет публикации IPFS. Новые финансовые модули потребуют своих правил.

Источники: снимок Pons frontend `package2-20261007T151240Z`, chunk-21/chunk-8;
проверенный `PonsV2LaunchDeployer.sol` из `package2-20261007T145547Z`, строки
59–63 и 194–205: контрактные пределы 64/16/512/2048/256 байт; UI-ограничения
имени, тикера и описания строже. Снимки сохранены в `.local/research/` и не заменены.
API CID: https://github.com/multiformats/js-multiformats;
декодирование: https://sharp.pixelplumbing.com/api-input/.

Проверено: 20 unit/API тестов, включая прямой обход UI, неверные тела запросов,
редакцию ошибок RPC и повреждённые картинки; 6 браузерных сценариев, включая
1000% / -5000 и запуск через сервер на локальном fork. Исходный код пакета пока
не закоммичен; результаты относятся к рабочему дереву поверх 8608cac.
