# Разделение комиссий — локальный пакет 08.10.2026

Согласованный пакет: призы/команда/обслуживание с неизменными долями и получателями
при создании. `LocalFeeSplitter` вставляется между collector и ShortProgram.
Сумма bps=10000, призовая доля положительная. Нулевые team/operations допустимы.
Адреса получателей ненулевые даже для нулевой доли; их совпадение допустимо,
учёт долей остаётся раздельным. Monthly и переключение политик не реализованы.

Доли берутся из config.fees конструктора; интеграционный сценарий использует
проверенный validateConfig пресет, отдельные сценарии другие распределения.
Deployment из UI пока не подключён, форма адресов получателей будет частью него.

Учёт округления: для каждого направления accumulated entitlement =
floor(totalReceived*bps/10000). Каждое поступление добавляет разницу с предыдущим
entitlement. Выплаты не сбрасывают накопленный счётчик. Разбиение одной суммы
на много поступлений не меняет итоговые доли. Пока дробные части не образовали
целую минимальную единицу, до2raw единиц остаются зарезервированными в splitter.
Если новых поступлений больше не будет, этот остаток остаётся там: admin sweep
не предусмотрен. Переполнение lifetime totalReceived вызывает revert.

Получение и выплаты разделены: fund учитывает реальную дельту баланса; deliver
по индексу0/1/2 передаёт накопленный кредит фиксированному получателю. Любой
может оплатить gas вызова, но не перенаправить деньги. Призовая доля поступает
через fund программы, allowance обнуляется. Отказ team не блокирует другие
направления; revert сохраняет его кредит. Нет отдельного доступа администратора
к фондам. Operations — отдельный перевод, а не разрешение тратить призовые на gas.

Прямой перевод в splitter не признаётся доходом, не распределяется автоматически.
Политика донатов не выбрана. Поддержан обычный ERC20; rebase/outgoing transfer tax
не поддержаны. Конструктор ограничен31337, escrow/RNG тестовые. Это ещё не
основная сеть, не Pons sweep, не автоматический gas-converter или keeper.

Проверки в tests/contracts/short-cycle.mjs: полный escrow→collector→split→Short→claims
и отдельные выплаты; отказ team и retry; tiny receipts с промежуточными выплатами
против lump sum для90/5/5,33.34/33.33/33.33,100/0/0,0.01/99.99/0;
точные cumulative entitlement/reserve/solvency; invalid shares, чужой экземпляр,
неверный lane, прямое пополнение без изменения credit.
