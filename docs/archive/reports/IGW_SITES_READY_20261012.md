## Публикация и подключение выпуска

Пакет для публикации содержит статический IGW и только index.html хаба.
При публикации сохранить предыдущие releases, проверить исходные symlinks,
установить отдельные новые releases и проверить HTTPS, CSP и SHA256.
Сайт действующего QIANQI и сервисы исполнения в этот пакет не входят.

После подтверждённого выпуска зарегистрировать реальный контракт и домен
igw.qianqi.site в проектном API по процедуре handoff. Появления контракта в сети
самого по себе недостаточно. После регистрации новая правка страниц не нужна.
Фактический контракт и статус общего каталога обновляются отдельно по результату выпуска.
