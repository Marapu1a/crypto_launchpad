## Продолжение

1. Владелец просматривает параметры и бюджет; перед включением подписей повторить
   balance/pins/finality/estimate. Сохранение запуска фиксирует input/profile.
2. Подписи выполняются расширением владельца, не сервером. Финансовый worker
   не включать автоматически после создания контрактов.
3. После deployment — bind/policy, регистрация домена, проверка API/кабинета,
   уведомлений и свежий backup, затем отдельная активация обслуживания.
4. Owner UI проверяет отдельные закрытые копии ключей IGW под своим OS user.
   При установке выключенного handoff для `launchpad-draw` заменить owner-only
   пути credentials на уже установленные worker paths:
   `/var/lib/crypto-launchpad/draw/{executor,publisher}/igw.json` и
   `/etc/crypto-launchpad/draw-secrets/{executor,publisher}.password`.
   Сверить адреса/ключи; экспорт owner UI не включать в worker без этой проверки.
