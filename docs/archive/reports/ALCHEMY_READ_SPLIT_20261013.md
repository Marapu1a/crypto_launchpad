# Alchemy read endpoint: локальный пакет и серверная проверка

13.10.2026. База e3585b6 + незакоммиченные изменения. Production endpoint и
боевые отправки этим пакетом не переключались. Проверки с VPS выполнены
read-only, без загрузки signer; небольшие диапазоны, не полный catch-up.

## Реализовано

В draw-runtime-v2 добавлен опциональный readRpcFile. Обычные чтения направляются
в отдельный provider; signer остаётся подключён к rpcFile. traceRpcFile остаётся
отдельным источником debug_traceTransaction. Резерв выбирается конфигурацией:
автоматического переключения или повтора отправки транзакций нет.

Nonce, gas estimate, broadcast и getTransactionReceipt для исполнения остаются
на исходном provider. Исторические receipts сканер читает через send либо
getReadTransactionReceipt отдельного read provider. Перед использованием
проверяется chainId4663; проверки canonicality в сканере сохранены.

readLogBlockRange (1–1000) задаёт размер запроса logs; readScanBlockLimit (1–5000)
ограничивает продвижение за проход. Для проверенного Free endpoint диапазон logs
должен быть 10. Лимит прохода — настройка нагрузки, не количество доступных
архивных блоков. Настройки по умолчанию сохраняют прежнее поведение.

## Проверка на VPS

- Free Alchemy: chainId4663, finalized и исторический блок82616126 читаются.
- eth_getLogs на1000 блоков: HTTP400 / -32600, ответ провайдера явно ограничивает
  Free tier диапазоном10 блоков. debug_traceTransaction требует платный тариф.
- QIANQI: отдельная копия index в /tmp/rpc-shadow-11u7yfif/index.json; исходный
  config использовался без изменения identity. Первый опыт с изменённым путём
  в config отвергнут checksum/config guard до сети. Повтор с оригинальной
  identity и отдельным statePath успешен: 87394382→87394392, target87506083,
  7.6сек, 95 RPC-вызовов: chainId3, block22, code25, call43, logs2.
  Вычисленный статус catchingUp/admitted; production snapshot не публиковался.
- IGW: в памяти отдельные policy/ledger из read-only SELECT; signer и production
  writes отсутствовали. Курсор87394382→87394392, finalized87506083,19 событий
  сохранены. Запрещённая трассировка дала evidence-unavailable, ready0;
  неизвестные маршруты остались route-not-identified. 14 вызовов:
  chainId7, block6, logs1. Это проверка небольшого участка и очереди, не полного
  финансового прохода. Она использовала установленный сканер с ограниченной
  конечной высотой; новые параметры диапазона отдельно проверены unit-тестом.

Локально22 адресных теста PASS: маршрутизация read/trace/send, wrong chain,
недоступный trace, discovery/deferred queue, сохранение nonce/gas/broadcast,
сканирование10-блочными порциями без пропусков, старые runtime guards.

## Границы и следующий шаг

Free Alchemy пригодна для ограниченного чтения/резервного обнаружения покупок,
но достаточность бесплатной месячной квоты и скорость полного catch-up не
доказаны. Высота finalized на проверке была примерно на111700 блоков впереди
сохранённого курсора. Большой backlog нельзя прогонять бесконтрольно.

Остановленный основной RPC всё ещё блокирует финансовые операции: разделение
чтения не означает автоматического восстановления выплат. QIANQI financial
worker/его trace preparation в этот кодовый пакет не перенастраивались.

Перед production: отдельный release/rehearsal, измерение ограниченного catch-up,
выбор бюджета запросов и проверка состояния незавершённых операций. Не покупать
тариф и не менять финансовые RPC молча. Статус этого документа — подготовлено
и адресно проверено, НЕ опубликовано.
