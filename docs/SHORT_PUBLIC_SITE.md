# API и страница нового Short

Пакет 10.10.2026, исходная база `f972450`. Реализован локально; миграция014,
службы и домены на VPS не устанавливались. QIANQI не изменён.

## Данные и изоляция

Runtime после прохода публикует отдельный снимок `short-public-v1` в
`short_public_views`. Данные контрактов читаются на блоке finalized ledger;
проверяются ветка, runtime hash программы, checksum policy/state и frozen draw.
Старшая revision или более свежий блок не перезаписываются старым снимком.
При ошибке сохраняются прежние значения с признаком сбоя обновления.
Ошибка проекции не повторяет финансовую транзакцию и не изменяет журнал.

`GET /api/short` возвращает модули проекта, snapshot, observedAt, stale и service.
Проект определяется существующим allowlist домена; параметры подмены проекта
не поддерживаются. Роль API читает только публичную таблицу под project RLS,
доступа к `production_senders` нет. Общая роль БД сохраняет прежнее ограничение:
изоляция контекста внутри приложения не равна отдельной роли на каждый токен.

Снимок содержит фонд, обязательства, последний draw, условия, общие начисления
билетов, checkpoint и finalized block. Policy, секреты, raw transactions и
исключения RPC наружу не сериализуются. Метаданные берутся из owner launch journal
после проверки checksum; отсутствие журнала допускает пустые метаданные.

## Страница

В общем сервере `SHARED_PROJECT_SITE=1` включает страницу `/` или `/project.html`
для зарегистрированных `project_domains` и статические assets из `dist`.
По умолчанию сервер остаётся API-only. Настройка DNS/reverse proxy — следующий
серверный этап. Owner UI через этот обработчик не публикуется.

Страница обновляется каждые30 секунд в видимой вкладке и вручную. Снимок старше
120 секунд отмечается устаревшим; отсутствие первого снимка не изображается нулём.
При недоступности API сохраняются последние значения с предупреждением.
Ожидание времени сверяется с timestamp блока: локальный таймер не обещает запуск.
Paused, blocked, пропавший heartbeat и ошибки проекции видны отдельно.

Билеты показаны как начисленные за всё время, включая использованные, а не текущий
баланс участия. Очередь регистрации включает только уже распознанные eligible
покупки; неизвестные маршруты этот счётчик не измеряет. Поздние подтверждения
не меняют frozen draw. Розыгрыш без победителя показан явно.
Личного кабинета, полной истории, торговли и кнопки claim в этом пакете нет.
Старый локальный Studio при отсутствии `/api/short` показывает только карточку
проекта; его процесс в этом пакете не перезапускался.
