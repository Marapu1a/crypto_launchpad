# Общий бот проектов

12.10.2026, исходная точка c50337a + незакоммиченные пакеты routes/wallet/recognition.
Владелец согласовал первую версию: каталог QIANQI/IGW со ссылками, коротким
описанием и адресом контракта; отдельного нового бота создаёт сам через BotFather.

## Реализовано

Единый публичный реестр — `apps/hub/site/projects.json`: сайт, статус,
описание, адрес, покупка, общий X `https://x.com/ui_uallas`.
В нём нет ключей, chat IDs и финансовых настроек. Код бота — `server/project-bot/`.

`/start`, `/projects`, `/help` просят название, тикер или адрес контракта; `/qianqi`, `/igw`
и `/start igw` открывают карточку. Кнопки: сайт, X, покупка, обозреватель,
контакт создателя в Telegram, дополнительные ссылки проекта, отдельное сообщение
с адресом и кнопкой копирования, возврат к поиску. Названия/тикеры ищутся без
учёта регистра и лишних пробелов; полный адрес — только по точному совпадению.
Частичное название от трёх символов даёт карточку или выбор до15 совпадений;
для большого числа совпадений предлагается уточнить запрос полным контрактом.
Неизвестный токен получает явное «No match in our project catalog».
Для ещё не выпущенных проектов карточка не имеет кнопок покупки/контракта.
IGW уже выпущен: текущий каталог содержит его контракт и ссылку Pons.
Наличие сайта само по себе не меняет статус токена.
Меню и карточки пока на английском, как сайты проектов.

Бот отвечает только в личном диалоге на входящие сообщения и нажатия кнопок.
Рассылок, доступа к кошелькам, подписей, балансов, уведомлений и привязки
Telegram-аккаунта к кошельку нет. Не использует служебного notification-бота.

Хаб содержит статические карточки, сгенерированные из того же реестра:
`npm run catalog:build`. Эта команда также обновляет описание/meta IGW на сайте.
`npm run catalog:check` проверяет отсутствие рассинхронизации перед публикацией.
Изменение реестра требует сборки статических страниц и перезапуска бота.
Публикация хаба и запуск Telegram-процесса выполняются отдельно.

## Подключение нового бота

1. Владелец создаёт отдельного бота. Токен сохраняется в игнорируемом файле
   `apps/hub/hub_key.txt` (фактический файл владельца; исключён правилом hub_key.*); значение не включать в репозиторий/команды/логи.
2. Указать полученный username без `@` в `botUsername` реестра.
3. Запуск: `npm run bot:projects -- apps/hub/hub_key.txt`. Необязательные аргументы после `--`:
   абсолютный путь token file и state file. На Linux token file должен иметь600.
4. При старте `getMe` проверяет совпадение username, `getWebhookInfo` — отсутствие
   другого webhook. Чужой webhook не удаляется. Второй poller не запускается.
5. Владелец открывает `https://t.me/<username>?start=igw` и проверяет карточку.
   После этого отдельно публикуется ссылка бота на сайтах/в метаданных токенов.

Обслуживание — long polling, один процесс. Offset сохраняется атомарно в
`.local/project-bot/state.json` после обработки сообщения. При сетевой ошибке
или429 ответ повторяется; блокировка бота пользователем не задерживает остальных.
401/409 и ошибки конфигурации останавливают процесс. Тексты сообщений, chat IDs
и токен не записываются в журнал. Хранятся только ID бота и offset.

После сбоя между отправкой карточки и сохранением offset карточка может прийти
повторно: это не обещание exactly-once доставки. После жёсткого завершения может
остаться `.lock`; перед его удалением проверить PID и отсутствие работающего бота.
Не запускать второй экземпляр с другим state file: Telegram409 остановит конфликт.

## Текст IGW и источники

Короткое описание, согласованное владельцем:

> IGW is a meme token with ticket-based draws. Eligible purchases earn tickets for a chance to win USDG. Small purchases add up, and unused tickets carry forward.

Дополнение для сайта:

> Or maybe it’s a magical airship carrying a crew of enchanted acorns on a thousand-year voyage from some distant galaxy to Saratov. To buy dried fish at the market. Who knows.

Логотип: `tokens/IGW/igw_logo.png`. При выпуске IGW загружен настоящий IPFS CID;
зафиксирован в [профиле](IGW_LAUNCH_PROFILE.md). Технический placeholder репетиции
не используется как адрес выпущенного логотипа.

Адрес QIANQI и Pons-ссылка сверены12.10.2026 с HTML https://init.qianqi.site/:
`0x6EA39A23AA46E51CA6CD2d1cbc0B5bfb29ECB216`.
Это чтение опубликованных ссылок, не новая проверка контрактов/состояния сети.
Explorer строится для того же адреса в Robinhood Chain.

API: [Telegram Bot API](https://core.telegram.org/bots/api), прочитано12.10.2026:
getUpdates/offset, getMe/getWebhookInfo, sendMessage, answerCallbackQuery,
InlineKeyboardButton.copy_text. Не требуется Telegram SDK или платная услуга.
