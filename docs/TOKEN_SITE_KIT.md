Обновление 12.10.2026: [пакет опубликован](archive/reports/TOKEN_SITE_KIT_RELEASE_20261012.md).
Ниже сохранены устройство сборки и ограничения локального preview. Дальнейшее
расширение по решению владельца пока отложено.

Согласовано владельцем 12.10.2026: постепенно пересобрать QIANQI и IGW из общих
настраиваемых блоков, сохранив оформление. Футер — общий компонент.

## Первый локальный пакет

- `src/site-kit/render.mjs`: единый статический футер и каркас результатов/ближайших
  розыгрышей. Имена и контакты берутся из общего каталога, оформление — из config.
- `footer.js`: отдельное контактное окно, Escape, backdrop, возврат фокуса;
  поддержка существующих переводов QIANQI. Кошелёк не переиспользует это окно.
- `site.css`: общие компоненты с двумя цветовыми темами. Маскот ограничен размерами.
- `tokens/{QIANQI,IGW}/site.config.json`: картинки, focal point desktop/mobile,
  палитра, футер, полезные ссылки и начальные подписи карточек.
- `draws.js`: новый API v2 отображает реальные модули из проверенного ответа IGW,
  точные суммы USDG, последний доступный результат, delayed/unavailable состояния.
  Awarded не выдаётся за paid; последняя запись не выдаётся за полную историю.
- QIANQI сохраняет прежние app.js/overview.js, историю с пагинацией и переводы;
  заменён только каркас DOM, требуемые идентификаторы сохранены.

Это первый этап переноса: верхние блоки, правила и кабинет ещё используют свои
исходные оболочки. Размеры/композиция верхнего баннера пока задаются их CSS;
общая конфигурация задаёт картинку и object-position, но не произвольный layout.
Редактора формой ещё нет. Параметры рисунка не меняют правила программы.
Заглушки config.draws не включают финансовые модули; v2 показывает модули API.
QIANQI v1 требует обе существующие программы — сборщик проверяет это.

## Сборка и просмотр

```
npm run sites:build
npm run sites:preview
```

- QIANQI: http://127.0.0.1:4200/
- IGW: http://127.0.0.1:4201/

Результаты только в `.local/token-sites/`; текущие сайты, исходный rh_project и
vendor не изменяются. Preview привязан к loopback, реальные API отключены.
Поэтому локальный preview не показывает live-состояние фондов/билетов.
Фиктивные суммы используются только в browser-тесте через перехват запросов.

QIANQI собирается из ранее сохранённого публичного статического снимка
`.local/qianqi-front-review/site` и Git overlay `tokens/QIANQI/site-overrides`.
Источник снимка: публичный release init-20261011-161417, чтение 11.10.2026;
см. README overlay и SITES_RELEASE_20261012. Можно явно указать другой проверенный
публичный каталог через `QIANQI_PUBLIC_SITE_BASE`. Это переходная зависимость:
на чистом checkout без снимка сборщик остановится. Секреты/состояние не импортируются;
список копируемых публичных каталогов и файлов задан явно.

Сборщик читает нынешние оболочки IGW и overlay QIANQI, заменяет ограниченные
компоненты с проверкой наличия регионов. Это адаптер миграции, не универсальный
HTML-парсер. Хэши входных оболочек/config и всех выходных файлов — build.json.
Описание IGW/история, SEO description и canonical обновляются из каталога при сборке.

## Индикатор проверки проекта — локальный пакет 13.10.2026

Общий project-pulse в src/site-kit подключён к локальным сборкам IGW/QIANQI.
Стили отдельно, состояние вычисляется по исходным observedAt; предел свежести
120 секунд, допустимое опережение часов 30 секунд. IGW дополнительно проверяет
service.observedAt/status/stale/projectionFailed; фонд ниже minimumFundRaw
показывается как Prize fund growing. QIANQI подтверждает свежесть данных
indexerState=caughtUp, но не выдаёт её за heartbeat исполнителя.

Хаб встраивает project-status.html каждого проекта отдельным iframe; этот файл
генерируется sites:build. Публиковать хаб следует после публикации этих файлов
на сайтах проектов. Production в этом пакете не изменялся.

Локально: SITE_PREVIEW_LIVE=1 npm run sites:preview — read-only proxy только
/api/project, /api/draws (IGW), /v1/overview (QIANQI). IGW :4201, QIANQI :4200,
хаб :4202. Без флага API остаётся недоступным, как в прежнем preview.
Проверка компонента: node tests/studio/project-pulse.mjs при запущенном preview.

После просмотра: для устаревших данных убрана надпись Draw updates delayed;
остаётся Last verified с исходной датой и нейтральным индикатором.
Свежесть по-прежнему проверяется, дата не заменяется текущим временем.

Время Last verified отображается в часовом поясе и формате браузера посетителя,
с явным смещением GMT/UTC. ISO datetime сохраняет исходный момент проверки.
Проверены Москва, Нью-Йорк (зима/лето) и Токио с переходом даты.
