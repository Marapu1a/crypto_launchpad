## Газ

Начальных0.001ETH executor не хватило на доставку доли splitter. Worker вернул
`native-balance` и сохранил намерение, не завершился аварийно. Репетиционный
скрипт после записи этого факта добавил0.02 **локального fixture ETH**, продолжил
ту же операцию. Production worker не пополняет кошельки автоматически.

Фактические затраты по receipts всех служебных транзакций этого прогона:

Это расход на покупки/регистрации и один цикл конкретного исторического форка,
без deployment и пользовательских approve/buy. Не тариф production и не
доказательство, что следующий цикл потребует столько же.0.02ETH — тестовый запас,
не измеренная потребность. Уведомления Telegram этим прогоном не отправлялись.

## Повторение и материалы

`scripts/rehearse-owner-draw.mjs <owner-server.json> <project UUID> --exercise`
предназначен только для свежего уже развёрнутого Short-only v2 с билетом10USDG
на закреплённом частном fork82000000. Он проверяет schema, rehearsal mode,
loopback RPC/PG и точный instanceId; production и чужие среды отвергаются.
Фиксированная историческая RNG-репетиция использует lead3600 секунд.
Повторный `--exercise` после появления runtime отвергается, чтобы не повторять
покупки. После неудачного прогона сначала разобрать сохранённые journal/report.

`--serve` запускает страницу и worker на127.0.0.1:4189, регистрирует только
локальный hostname этого проекта, не включает export для публичной сети.
Остановка: создать `draw-runtime.stop` внутри каталога owner-стенда; процесс
дождётся текущего прохода. Перед повторным запуском удалить только этот stop-файл.
Не перезапускать весь fork: иначе потеряется локальная цепочка.
