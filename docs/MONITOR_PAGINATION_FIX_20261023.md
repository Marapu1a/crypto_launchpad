# Восстановление пагинации монитора — 23.10.2026

## Причина

В 19:48 МСК сборщик начал возвращать `page_limit` для POD
`0xa2a6d216e934b42f412dba6202a2ff69f535dbb7`. Последний полный кеш был
до 19:40. Каждый проход снова читал первые 20 страниц; прогресс не сохранялся.
Снимок API переносил общий `complete=false` на семь интервалов и показывал
неполные повторные измерения вместо сохранённых полных. База полные интервалы
сохраняла. Уведомления при неполной базе сравнения подавлялись корректно.

## Исправление

Код `584fe7c`: курсор, строки и граница времени незавершённого прохода сохраняются
в `trade-cache.json` отдельно от подтверждённого диапазона. Следующий проход
продолжает загрузку, затем обновляет свежую часть истории. Повтор курсора и
нарушение порядка страниц не подтверждают полноту. Общие ограничения сохранены:
300 запросов / 180 секунд на проход, 20 страниц на токен; только Pons HTTP API.

Полнота определяется для каждого интервала по пересечению с первым часом токена
и подтверждёнными диапазонами. Непрочитанные сделки с той же временной меткой
на границе страницы не считаются загруженными. Для графиков и текущего снимка
сохранённый полный интервал имеет приоритет над неполным повторным сбором.
Полнота истории с рождения токена остаётся отдельным признаком таблицы.
