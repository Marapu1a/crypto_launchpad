# Pattern Watcher

Preparation only — no token deployed or launch configuration activated.

The token accompanies the Pattern Watcher monitor. The service reports observed
Pons activity and relationships, without predicting returns or labelling wallets
as bots. Token launch and service payment remain part of the agreed product.

## Launch preparation

Use the [shared servicing model](../../docs/TOKEN_SERVICE_MODEL.md) and isolated
per-token funds, state, tickets and journals. No copied QIANQI or IGW keys/config.

Before producing an executable launch package, settle symbol, public URLs,
service pricing/holder discount and draw/fee parameters. The discussed monthly
draw and holder benefits are not silently converted into financial configuration.

Then prepare public metadata and image upload, validate the selected launch
profile and budget, rehearse servicing with test data, and review the complete
package before any signing, transfer or public launch.
