# Pattern Watcher

19.10.2026. Preparation only: no PW token deployed or production activation.

The token accompanies the Pattern Watcher monitor. The service reports observed
Pons activity and relationships, without predicting returns or labelling wallets
as bots. Token launch and service payment remain part of the agreed product.

## Launch preparation

[Launch passport](../../docs/PW_LAUNCH_PASSPORT.md) records remaining decisions;
[machine-readable passport](launch-passport.json) is deliberately non-executable.
[Preparation profile](preparation.json) and [approved rules](../../docs/PATTERN_WATCHER_RULES.md)
are the source for economics: ETH pair, 3% creator fee, received fees split
60/20/20, monthly draw and holder periods, 0.001 ETH ticket, 0.005 ETH draw
fund/prize thresholds, 0.0005 ETH minimum holder payment, no buyback/burn in v1.

The [owner UI](../../docs/PW_OWNER_UI.md), launch coordinator, fee/draw service,
holder execution and bounded recovery are implemented and tested locally.
This is not production admission. Real roles, spending limits, exclusions,
published metadata, complete release rehearsal and final review remain pending.
Service pricing/holder discounts are a later package, not silently added to launch rules.

Use the [shared servicing model](../../docs/TOKEN_SERVICE_MODEL.md) with isolated
per-token funds, state, tickets and journals. No copied QIANQI/IGW keys or live config.
