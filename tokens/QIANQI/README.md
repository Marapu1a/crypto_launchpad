# QIANQI

- `site/` — полный публичный исходник сайта, не только overlay.
- `site.config.json` — оформление и параметры общих компонентов.
- Изображения в этом каталоге — исходные ресурсы оформления.
- Финансовый адаптер — `server/adapters/qianqi/` в корне репозитория;
  общий runtime — `server/shared/`, site-kit — `src/site-kit/`.

Из корня: `npm run sites:build`, `npm run sites:preview` (порт 4200).
При переносе 16.10.2026 публичный снимок `.local/qianqi-front-review/site`
объединён с отслеживаемыми site-overrides. Сборка побайтово совпала с прежней.
Исходники не скачивались заново и не заменялись старой версией rh_project.

Исправления recognition/finality и их тест из старого checkout совпадают с активным
адаптером. Старые ops и страницы не заменяют текущую платформу. История и изменения
сохранены локально, rh_project не удалён. [Карта переноса](../../docs/REPOSITORY_LAYOUT_PLAN.md).
