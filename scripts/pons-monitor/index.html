Предыдущие 30 минут и последние 5 минут. Адрес считается один раз в каждом окне; один человек может владеть несколькими адресами.

Кошельки покупателей — не текущие холдеры. Объёмы — суммы покупки из API Pons, не доход и не капитализация. ETH и USDG не складываются. Топ-3 — доля трёх крупнейших покупателей в объёме выбранного окна; это не доказательство накрутки.

Фоновый сбор раз в 5 минут; кнопка запрашивает свежий снимок. Данные отстают минимум на минуту для индексации. История хранится 28 дней, пока работает локальный сборщик. Неполные интервалы исключаются из сравнения. «Широкий ажиотаж»: покупателей не меньше 75-го процентиля сегодня, минимум 3 токена с 3+ покупателями, доля лидера не больше 40%. Пороги экспериментальные; адреса не гарантируют разных людей.
